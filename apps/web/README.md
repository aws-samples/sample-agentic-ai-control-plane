# Dashboard (`apps/web`)

The Next.js management dashboard and agent playground for the Agentic AI Platform.

See the [root README](../../README.md) for full setup, deployment, and local
development instructions.

## Quick start (local)

```bash
# from the repo root
docker compose up -d          # local Postgres
pnpm init                     # writes .env.local
pnpm dev                      # starts the dashboard at http://localhost:3000
```
